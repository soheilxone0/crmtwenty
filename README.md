# CRM فارسی (crmtwenty)

یک CRM کامل و مدرن به زبان فارسی، با تقویم شمسی، برای نصب روی **هاست اشتراکی پلسک** (Plesk).
پایه‌ی آن [Krayin CRM](https://github.com/krayin/laravel-crm) نسخه‌ی 2.2.8 است (لاراول ۱۲، مجوز MIT).

## امکانات

- **رابط کاملاً فارسی و راست‌به‌چپ** با فونت وزیرمتن (فونت روی خود سایت است و به گوگل وصل نمی‌شود).
- **تقویم شمسی در همه‌جا**: انتخابگر تاریخ (شروع هفته از شنبه)، تقویم فعالیت‌ها، ستون‌های جدول‌ها، فیلترها، داشبورد و گزارش‌ها، ایمیل‌ها و PDF پیش‌فاکتور.
  تاریخ‌ها در پایگاه‌داده میلادی ذخیره می‌شوند و فقط نمایش و ورودی شمسی است.
- **ایمیل شرکت (SMTP) از پنل مدیریت**: مسیر «پیکربندی ← ایمیل ← ایمیل شرکت (SMTP)»، همراه دکمه‌ی «ارسال ایمیل آزمایشی».
- **ثبت‌نام با ایمیل**: فعال‌سازی حساب با ایمیل، ارسال دوباره‌ی ایمیل فعال‌سازی و در صورت نیاز تأیید حساب توسط مدیر.
  همه از مسیر «پیکربندی ← ایمیل ← ثبت‌نام و تأیید ایمیل» تنظیم می‌شود.
- **فراموشی رمز عبور** با ارسال پیوند بازنشانی به ایمیل.
- امکانات اصلی CRM: سرنخ‌ها (Lead) و پایپ‌لاین کانبان، مخاطبین و سازمان‌ها، پیش‌فاکتور، محصولات و انبار، ایمیل (IMAP)، فعالیت‌ها و تقویم، فرم‌های وب، اتوماسیون، نقش‌ها و دسترسی‌ها، گزارش‌ها و داشبورد.
- واحد پول پیش‌فرض ریال (IRR) و منطقه‌ی زمانی Asia/Tehran.

## پیش‌نیازهای هاست

| مورد | مقدار |
|---|---|
| PHP | ‎8.3‎ یا بالاتر (در پلسک: Hosting Settings ← PHP version) |
| افزونه‌های PHP | `intl`، `gd`، `mbstring`، `pdo_mysql`، `zip`، `curl`، `fileinfo`، `openssl` |
| پایگاه‌داده | MySQL 8 یا MariaDB 10.3+ |
| محدودیت حافظه‌ی PHP | دست‌کم `256M` |

## نصب روی پلسک (Git pull & deploy)

پلسک نمی‌تواند `composer install` یا `npm run build` اجرا کند. برای همین GitHub این کار را انجام می‌دهد.
هر بار که شاخه‌ی `main` به‌روز شود، گردش‌کار **Build for Plesk** یک نسخه‌ی آماده‌ی اجرا را، همراه `vendor/` و فایل‌های ساخته‌شده، روی شاخه‌ی **`production`** قرار می‌دهد.
پلسک فقط همین شاخه را pull می‌کند.

### ۱) پایگاه‌داده

در پلسک بخش «Databases ← Add Database» را باز کنید، یک پایگاه‌داده‌ی MySQL بسازید (مثلاً `crm`) و نام کاربری و رمز آن را یادداشت کنید.

### ۲) اتصال به گیت‌هاب

۱. در پلسک به «Websites & Domains ← crm.arounidea.com ← Git» بروید.
۲. نشانی مخزن را وارد کنید: `https://github.com/soheilxone0/crmtwenty.git`
   اگر مخزن خصوصی است، گزینه‌ی SSH را انتخاب کنید و کلید عمومی‌ای را که پلسک نشان می‌دهد در گیت‌هاب در «Settings ← Deploy keys» اضافه کنید.
۳. **Branch** را `production` بگذارید.
۴. «Deployment mode» را روی **Automatic** بگذارید.
۵. «Deployment path» را پوشه‌ی `crm.arounidea.com` بگذارید.

### ۳) ریشه‌ی سایت (Document root)

بهترین حالت: در «Hosting Settings» مقدار **Document root** را `crm.arounidea.com/public` بگذارید.

اگر نتوانستید آن را عوض کنید، مشکلی نیست: فایل `.htaccess` ریشه همه‌ی درخواست‌ها را به پوشه‌ی `public/` می‌فرستد و فایل‌هایی مثل `.env` و `vendor/` از بیرون در دسترس نیستند.

### ۴) نصب‌کننده‌ی تحت وب

۱. `https://crm.arounidea.com` را باز کنید.
   در اولین بازدید فایل `.env` با یک کلید امن ساخته می‌شود و به `/install` هدایت می‌شوید.
۲. اطلاعات پایگاه‌داده‌ی مرحله‌ی ۱ را وارد کنید.
۳. زبان را **فارسی**، منطقه‌ی زمانی را **Asia/Tehran** و واحد پول را **ریال ایران (IRR)** انتخاب کنید.
۴. حساب مدیر را بسازید.

> اگر در پایان نصب تصویرها یا فایل‌های بارگذاری‌شده نمایش داده نشد، احتمالاً هاست اجازه‌ی ساخت symlink نمی‌دهد. در این حالت در «File Manager» پلسک یک لینک به نام `public/storage` بسازید که به `storage/app/public` اشاره کند، یا از پشتیبانی هاست بخواهید این کار را انجام دهد.

### ۵) ایمیل شرکت

۱. وارد پنل شوید و به «پیکربندی ← ایمیل ← ایمیل شرکت (SMTP)» بروید.
۲. مقادیر زیر را وارد کنید:
   - **میزبان**: معمولاً `mail.arounidea.com`
   - **پورت**: `465` با «خودکار» یا SSL، یا `587` با STARTTLS
   - **نام کاربری و رمز**: یک صندوق ایمیل که در پلسک ساخته‌اید، مثلاً `crm@arounidea.com`
۳. با «ارسال ایمیل آزمایشی» تنظیمات را امتحان کنید و سپس **ذخیره** کنید.

بعد از این، ایمیل‌های فراموشی رمز، فعال‌سازی حساب و اعلان‌ها با همین حساب فرستاده می‌شوند.

### ۶) ثبت‌نام کاربران (اختیاری)

مسیر «پیکربندی ← ایمیل ← ثبت‌نام و تأیید ایمیل» را باز کنید. گزینه‌ها:

- **فعال بودن ثبت‌نام عمومی**: پیوند «ثبت‌نام کنید» زیر فرم ورود نمایش داده می‌شود.
- **الزام تأیید ایمیل** (پیش‌فرض روشن): کاربر تا روی پیوند ایمیل نزند، نمی‌تواند وارد شود.
- **نیاز به فعال‌سازی توسط مدیر**: به مدیران ایمیل می‌رسد و حساب تا فعال‌سازی در «تنظیمات ← کاربران» غیرفعال می‌ماند.
- **نقش کاربران جدید**: اگر خالی بماند، نقش محدود «کارشناس فروش» ساخته می‌شود. کاربران ثبت‌نامی هرگز نقش مدیر نمی‌گیرند.

### ۷) کارهای زمان‌بندی‌شده (اختیاری)

برای دریافت خودکار ایمیل‌های IMAP و اتوماسیون‌های زمان‌دار، در پلسک از مسیر «Scheduled Tasks» این دستور را هر دقیقه اجرا کنید:

<div dir="ltr">

```
/opt/plesk/php/8.3/bin/php /var/www/vhosts/arounidea.com/crm.arounidea.com/artisan schedule:run
```

</div>

مسیر بالا را با مسیر واقعی پوشه‌ی سایت خود جایگزین کنید.

### به‌روزرسانی

هر تغییری که در شاخه‌ی `main` ادغام شود، به‌طور خودکار روی شاخه‌ی `production` ساخته می‌شود و پلسک آن را pull می‌کند.
اگر نسخه‌ی جدید migration داشته باشد، یک بار از «Scheduled Tasks ← Run now» (یا SSH) این دستور را اجرا کنید:

<div dir="ltr">

```
php artisan migrate --force
```

</div>

## توسعه‌ی محلی

<div dir="ltr">

```bash
composer install
cp .env.example .env && php artisan key:generate
# set DB_* in .env, then:
php artisan krayin-crm:install
cd packages/Webkul/Admin && npm ci && npm run build
php artisan serve
```

## ساختار تغییرات فارسی

- `packages/Crmtwenty/Persian`: بسته‌ی اختصاصی این پروژه، شامل:
  - کلاس تقویم شمسی `Support/Jalali.php`
  - تنظیمات ایمیل شرکت `Support/MailSettings.php`
  - ثبت‌نام و تأیید ایمیل
  - صفحه‌های فارسی و قالب‌های ایمیل
- `packages/Webkul/Admin/src/Resources/assets/js/jalali`: تبدیل تاریخ و انتخابگر تاریخ شمسی، که جایگزین flatpickr شده است.
- `packages/Webkul/Core/src/Core.php`: تابع `core()->formatDate()` در زبان فارسی تاریخ را شمسی برمی‌گرداند.
- `lang/fa`: پیام‌های اعتبارسنجی، ورود و بازنشانی رمز به فارسی.
- `tests/Feature/Persian`: آزمون‌های تقویم، ثبت‌نام، تأیید ایمیل و SMTP.
